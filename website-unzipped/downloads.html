Per-article formats

Open any article and use the Download this article panel in the sidebar. Each article can be saved as:

  • Markdown (.md) — with YAML front matter, ready for Obsidian, Logseq, Jekyll, Hugo, Pandoc or a git repository.
  • Web page (.html) — a single self-contained file that opens in any browser, offline.
  • Print / Save as PDF — opens the browser print dialog with a dedicated print stylesheet; choose “Save as PDF”.
  • Plain text (.txt) — the reading text only, no markup.
  • JSON (.json) — title, description, tags, date, author, word count, license URL and full Markdown body.
